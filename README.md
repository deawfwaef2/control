# 机械病毒：赤巢协议 · 快速开始

## 打开游戏

主交付文件：`/home/user/机械病毒-赤巢协议.html`

直接用现代浏览器打开即可。HTML 已内嵌全部美术、样式与脚本，不需要联网、安装依赖、注册账号或启动后端。

项目目录内的 `index.html` 与主交付 HTML 内容一致，适合静态 HTTP 预览。

## 第一场怎么开始

1. 主菜单选择 **地球守护者** 或 **赤巢意识**。
2. 点击 **接入作战**。剧情可逐句推进，也可以跳过。
3. 点击己方棋子，再点击高亮格移动 / 吃子。
4. 棋子在本阶段行动过一次就不能再动。可选择其他单位继续，也可提前结束阶段。
5. 点击 **结束阶段**：你本阶段行动 N 次，AI 得到 N 次额度。
6. 点击敌方棋子查看走法与意图；点击 **威胁视野**看当前攻击范围。
7. 先看左侧主要目标。不是所有关卡都要求清空敌人。

建议初次选择守护者，并在首关之后选择“先去玻璃花园”。这是更完整的救援与成长路线。红方与先过断桥的路线更依赖推演。

## 最重要的特殊规则

- 机娘被吃后改变阵营，不直接死亡。
- 攻击者进入目标格；被接管者移至攻击者原格。
- 新感染 / 解放的机娘锁定到下次己方阶段。
- 无人装置被吃则销毁。
- 固守消耗一次行动；不能零行动结束阶段。
- 撤离会离开当前关卡，机娘下关再出现。
- 真空与桥面坍塌会永久摧毁机娘。
- 终端踩上即改变归属，离开后仍保留归属。
- 最终核心有护盾，必须先控制两座终端。

## 存档与声音

- 自动保存使用浏览器 localStorage。
- 某些文件预览器使用不透明沙盒来源，会禁止 localStorage；游戏仍能在当前页面内运行。
- 建议下载 HTML 独立打开，或者使用 HTTP 直播预览，以获得更可靠的自动存档与下载权限。
- 右上角系统菜单可 **导出 / 导入 JSON 存档**。
- 导出取最近一个玩家阶段的快照，不在敌方执行到一半时截断动作。
- 合成音效默认关闭，点击右上角声音按钮开启。

## 快捷键

- `Space`：结束玩家阶段（焦点不在按钮或输入框时）。
- `Enter`：推进对白；焦点在按钮上时执行按钮。
- `Esc`：关闭菜单 / 跳过非选择型剧情 / 打开系统菜单。
- `Tab`：切换按钮与棋盘格，可用 `Enter` 操作。

## 项目文件

- `index.html`：打包好的单文件游戏。
- `index.template.html`：页面结构。
- `style.css`：响应式界面、棋子与演出样式。
- `data.js`：角色、关卡文本与故事。
- `engine.js`：棋类规则、战役状态与 AI。
- `ui.js`：渲染、交互、实时演出、声音与存档。
- `assets/`：原创生成图片及压缩后的 WebP。
- `build_game.py`：将素材与代码打包为单个 HTML，依赖 Python Pillow。
- `设计说明.md`：机制、关卡、爽点、AI 与当前范围说明。

## 当前性质

这是五关可通关的功能原型，非完整商业发行版。没有联网服务、配音影片或经过棋力认证的 AI。按用户此前的偏好，本次未运行测试，也未进行玩家平衡验证；规则与关卡仍可继续迭代。
